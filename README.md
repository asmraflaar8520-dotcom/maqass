# ✂️ مِقَصْ (Maqass) — نظام إدارة حجوزات وقوائم صالونات الحلاقة
> تطبيق ويب سحابي فائق الخفة ومجاني 100%، مصمم خصيصاً لصالونات الحلاقة في مصر للعمل مباشرة عبر **GitHub Pages** وقاعدة بيانات **Supabase (Free Tier)** دون خوادم أو تكاليف استضافة أو اشتراكات شهرية.

---

## ✨ المميزات الرئيسية (Core Features)

1. **صفر تكلفة وصفر خطوات بناء (Zero Build / GitHub Pages Ready):**
   - كود نقي بالكامل (`HTML5`, `CSS3`, `Vanilla ES6 Modules via CDN`).
   - لا يحتاج إلى `Node.js` أو `npm run build` أو `Webpack`.
2. **منع الحجز المزدوج على مستوى قاعدة البيانات (PostgreSQL GiST Constraint):**
   - حماية مستحيلة الكسر حتى مع تزامن مئات الزبائن في نفس اللحظة عبر امتداد `btree_gist`.
3. **حساب المواعيد بدقة التوقيت المحلي لمصر (`Africa/Cairo`):**
   - استخراج وتنسيق التواريخ محلياً لمنع مشكلة ارتداد المواعيد لليوم السابق بعد منتصف الليل.
4. **حظر العملاء المتخلفين تلقائياً (Auto-Blacklist Engine):**
   - عند تخلف العميل عن الحضور مرتين (`no_show_count >= 2`)، يُحظر رقمه آلياً من الحجز أونلاين.
5. **شاشة الحلاق للأيدي المشغولة (One-Tap Busy-Hands UX):**
   - أزرار عملاقة ملفتة (`بدأ الحلاقة`، `تم الانتهاء`، `لم يحضر`).
   - زر الاستراحة السريع (`is_paused`) لغلق الحجز فوراً وتنبيه الزبائن.
   - زر الزبون المباشر (`Walk-in`) مع فحص الفجوة الزمنية الذكي لمنع تعارض مواعيد الزبائن القادمين.
6. **تأكيد وتذكير عبر واتساب مجاناً 100% (`wa.me`):**
   - توليد رسائل بالعامية المصرية بضغطة زر واحدة ودون الحاجة للاشتراك في خدمات WhatsApp Business API المدفوعة.
7. **إحصائيات تشغيلية بحتة (خالٍ تماماً من الحسابات المالية):**
   - يركز فقط على رؤوس الزبائن المنجزة، نسب الالتزام بالحضور (Show-Up Rate %)، وحجم قائمة الانتظار.
8. **عداد زيارات ذري محمي (Session-Guarded Counter):**
   - يمنع استهلاك حصة Supabase المجانية عبر تسجيل الزيارة مرة واحدة فقط لكل جلسة متصفح.

## 🚀 خطوات النشر والتثبيت المجاني في 3 دقائق (Deployment Guide)

### الخطوة 1: إعداد قاعدة البيانات على Supabase
1. سجل حساباً مجانياً على [Supabase](https://supabase.com) وأنشئ مشروعاً جديداً (مثلاً: `maqass-barber`).
2. ادخل إلى **SQL Editor** من القائمة الجانبية.
3. انسخ كامل محتوى الملف [`supabase_schema.sql`](./supabase_schema.sql) والصقه في المحرر، ثم اضغط **RUN**.
4. مبروك! تم إنشاء الجداول، الفهارس، قيد منع الحجز المزدوج، سياسات الأمان RLS، ودالة عداد الزيارات.

### الخطوة 2: إنشاء حساب الحلاق (Barber Login)
1. من لوحة Supabase، اذهب إلى **Authentication** -> **Users**.
2. اضغط **Add User** -> **Create User**.
3. أدخل بريدك الإلكتروني وكلمة المرور الخاصة بك (مثلاً: `barber@salon.com` وكلمة مرور قوية).
4. استخدم هذا الحساب لتسجيل الدخول إلى لوحة التحكم [`dashboard.html`](./dashboard.html).

### الخطوة 3: ربط المفاتيح (Project Credentials)
افتح ملف [`js/config.js`](./js/config.js) وضع رابط المشروع والمفتاح العام:
```javascript
export const CONFIG = {
  SUPABASE_URL: 'https://YOUR_PROJECT_ID.supabase.co',
  SUPABASE_ANON_KEY: 'eyJhbGciOi...',
  // ...
};
```
*(أو يمكنك تخطي هذه الخطوة وسيقوم التطبيق بسؤالك عنها في نافذة منبثقة عند تشغيل الموقع لأول مرة، ويحفظها محلياً في متصفحك)*.

### الخطوة 4: النشر المجاني عبر GitHub Pages
1. ارفع المشروع إلى مستودع جديد على حسابك في GitHub.
2. اذهب إلى **Settings** الخاصة بالمستودع -> **Pages**.
3. تحت خيار **Build and deployment**:
   - **Source:** اختر `Deploy from a branch`.
   - **Branch:** اختر `main` واجعل المجلد `/ (root)`.
4. اضغط **Save**... في غضون دقيقة سيكون موقع صالونك حياً على الإنترنت ومتاحاً مجاناً مدى الحياة!

### الخطوة 5 (اختيارية): تفعيل الأكشن لمنع إيقاف قاعدة البيانات المجانية
- صممنا لك ملف أوتوميشن [`keep-alive.yml`](./.github/workflows/keep-alive.yml).
- اذهب إلى **Settings** المستودع -> **Secrets and variables** -> **Actions**.
- أضف المتغيرين:
  - `SUPABASE_URL`
  - `SUPABASE_ANON_KEY`
- سيقوم GitHub بإرسال إشارة استيقاظ لقاعدة بياناتك كل 3 أيام لضمان عدم دخولها في وضع الخمول (Sleep Mode) أبداً!

## 🔒 الأمان، العزل التام وسياسات RLS (Enterprise-Grade Security)
- **عزل الصالونات (Multi-Tenant Isolation):** كل صالون معزول برمجياً عبر سياسات Row Level Security (RLS) صارمة؛ لا يمكن لأي حلاق رؤية بيانات أو حجوزات أي صالون آخر.
- **الحجوزات للجمهور:** يسمح فقط بإنشاء حجز وقراءة المواعيد لحساب الأوقات الشاغرة فقط للصالون المحدد.
